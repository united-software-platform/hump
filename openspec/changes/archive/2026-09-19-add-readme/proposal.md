## Why

У репозитория Hump («Сортировочная горка») пока нет `README.md`: сторонний читатель на GitHub видит
только код и служебные файлы без представления о назначении проекта и его составе. Репозиторий уже
опубликован в организации `united-software-platform` и должен иметь входную точку документации, как
и другие проекты организации (пример — `sdd-developer-kit`).

## What Changes

- Добавлен `README.md` в корень репозитория со следующей структурой:
  - блок бейджей используемых технологий, пакетов и образов (в начале файла, до основного текста —
    по аналогии с `README.md` `sdd-developer-kit`);
  - базовое описание проекта: Hump («Сортировочная горка» — термин железнодорожной отрасли) —
    интеллектуальный маршрутизатор LLM-запросов, единая точка входа для Garden, Experience Mine
    и других систем, распределяющая запросы между моделями и AI-провайдерами с учётом типа задачи,
    требований и доступных ресурсов;
  - раздел «Состав» по образцу одноимённого раздела `sdd-developer-kit`: перечень используемых
    инструментов и сервисов с описанием роли каждого в проекте. На этом шаге в раздел входят:
    - [LiteLLM](https://www.litellm.ai/) — единый API-слой поверх LLM-провайдеров;
    - [Ollama](https://ollama.com/) — запуск локальных моделей.
- Раздел «Состав» и остальные разделы `README.md` (установка, команды, переменные окружения и т. д.)
  расширяются последующими изменениями по мере появления кода — в этой версии фиксируется только
  перечисленное выше.

## Capabilities

Изменение не затрагивает поведение системы: Hump ещё не содержит кода, а `README.md` — файл
документации. Спецификации не создаются и не изменяются (`skip_specs: true` в `.openspec.yaml`).

## Impact

- Новый файл: `README.md` в корне репозитория.
- Другие файлы и код не затрагиваются.
